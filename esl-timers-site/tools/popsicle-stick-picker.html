About this tool

A digital version of the classic cup-of-popsicle-sticks trick many teachers already use for cold-calling — except there's nothing to write out by hand, nothing to lose, and no risk of accidentally pulling the same stick twice in a row. Paste in your class list, tap the cup, and a name pulls up fairly, with the same no-repeat guarantee as every picker on this site: once everyone's had a turn, the pool automatically refills.

If you already run a physical stick-cup system in class, this works well as a backup for days you forget the real cup at home, or as a way to run the same fair system on a shared classroom screen so the whole class can see the pick happen, not just the teacher.

Works with any class size, no sign-up required, and the full roster stays visible below so students can see who's still waiting for a turn.
