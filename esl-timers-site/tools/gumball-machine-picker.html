About this tool

A gumball machine name picker for the classroom: turn the crank, the machine rattles, and a gumball rolls out of the chute with a student's name on it. It runs on the same fair no-repeat system as every picker on this site, so once a student has had their gumball, they're set aside until everyone else in the class has had a turn too.

The machine fills with one gumball per student, so the class can watch the pile shrink as the lesson goes on, and every pick lands in the "Already picked" tray below. The rattle and the roll out of the chute give cold-calling a bit of game-show suspense, which works especially well with younger learners and ESL classes, where being picked feels less stressful when it feels like a game.

Use it for warm-up questions, choosing who reads next, deciding turn order, or handing out classroom jobs. Paste in your class list, turn the crank as many times as you need, and use fullscreen mode to put the machine up on your projector. No sign-up, and any class size works.
