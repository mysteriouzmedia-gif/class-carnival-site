About this tool

Most random pickers only work with names — this one is built to race anything you type in, one item per line, which makes it useful well beyond turn-order. Paste in a vocabulary list instead of student names, and the race decides which word your class reviews first, second, third, and so on, turning a plain vocabulary drill into something with a bit of visible suspense.

It's a natural fit for warm-up reviews, spelling practice, or randomizing the order of a "word of the day" rotation across the week. Because it's the same underlying engine as the classic Race Timer, it works exactly as well with student names if you'd rather use it that way — there's nothing vocabulary-specific under the hood, just a different way of framing what you type in.

As always: any list length works, no sign-up required, and every race produces a different order, so review sessions don't get predictable.
