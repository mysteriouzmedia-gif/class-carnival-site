About this tool

A random student picker built around fairness: once a name's been picked, it won't come up again until every other name on the list has had a turn. That solves the classic problem with cold-calling — without a system, the same few names tend to get picked over and over, whether on purpose or not.

Paste in your class list, tap Pick a Student as many times as you need during the lesson, and watch the pool of remaining names shrink until everyone's had a turn — at which point it automatically refills and starts a fresh round. The full roster stays visible below the picker at all times, with used names greyed out, so both you and the class can see who's still in the running.

Works for any class size, needs no account, and is well suited to daily use — reset the pool manually at any point if you want to start a new round early.

Frequently asked questions

Is the Random Name Picker free?

Yes. The Random Name Picker is completely free — no sign-up, no student accounts and nothing to download. It runs in any modern web browser on a laptop, tablet, interactive whiteboard or projector.

Will the same student be picked twice?

No. Every student is picked once before anyone is picked again. When the whole class has had a turn, a fresh round starts automatically, so cold-calling stays fair.

Can I save my class list?

Yes. Type or paste your names once, then save them as a class in the “My classes” bar above the names box. Your saved classes load on every ClassCarnival tool. They are stored only in your own browser — nothing is uploaded.

Will it work on my classroom projector or whiteboard?

Yes. Press the fullscreen button in the top-right corner and the tool fills the screen, with text big enough to read from the back of the room. It also works on interactive whiteboards and tablets.
