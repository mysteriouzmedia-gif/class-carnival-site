About this tool

A playful jar-themed random picker — tap the jar, a sticker flies out and flips over to show whose turn it is, using the same fair no-repeat system as every other picker on this site. Once a student's name has come up, it's set aside until everyone else in the class has had a turn, so picking stays fair over the course of a lesson or a full day.

The lighter, more decorative framing tends to suit younger classes especially well, where a plain list or a bare name reveal can feel a bit flat — a small visual reward on each pick keeps the moment feeling fun rather than purely functional. Works for cold-calling, handing out a small task or reward, or deciding turn order for a quick activity.

Paste in your class list and the jar fills with one sticker per student. Every pick adds that student to the sticker chart below, so the class can see who's had a turn and which sticker they got — once everyone's on the chart, the jar refills for a new round. No sign-up, and any class size works.
