About this tool

A playful jar-themed random picker — tap the jar, and a name pops out dressed up with a couple of stickers, using the same fair no-repeat system as every other picker on this site. Once a student's name has come up, it's set aside until everyone else in the class has had a turn, so picking stays fair over the course of a lesson or a full day.

The lighter, more decorative framing tends to suit younger classes especially well, where a plain list or a bare name reveal can feel a bit flat — a small visual reward on each pick keeps the moment feeling fun rather than purely functional. Works for cold-calling, handing out a small task or reward, or deciding turn order for a quick activity.

Paste in your class list, tap the jar as many times as you need, and the roster below updates live to show who's still waiting for a turn. No sign-up, and any class size works.
