Fair picking, every time

A plain random pick can land on the same student three times in a row. Every picker on ClassCarnival avoids that: once a student has been picked, they're set aside until the rest of the class has had a turn, then the pool refills for a new round. You can see who has already been picked on screen, so students know the system is fair.

Which picker should I use?

Use the List Picker when you just need a name fast. The Gumball Machine and Popsicle Stick Cup add a few seconds of suspense that younger classes love. Lucky Envelope lets a student come up and choose an envelope themselves, Sticker Jar builds a sticker chart as you go, and Spin the Globe can give each student a country to talk about — handy for ESL speaking practice.

Made for the projector

Every picker has a big full-screen reveal, works in fullscreen mode, and can be run from the keyboard: press Space for the next pick. Paste in your class list and you're ready — no sign-up needed.
